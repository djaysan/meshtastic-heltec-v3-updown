Heltec V3 toggle firmware

Meshtastic 2.7.26 with the up/down/select input re-enabled and the side button mapped to presets. Chrome or Edge on desktop, node plugged in over USB.

Flash

Click the button, pick the USB serial port, then choose Install. A dialog asks whether to erase the device.

Leave "Erase device" unticked to keep your config: region, channels, presets, pins, name. The image refreshes bootloader, partition table and app only.

Tick "Erase device" only for a blank or bricked board. Everything on it is wiped and you reconfigure from scratch.

Your browser has no Web Serial. Use Chrome or Edge on desktop. Open this page over HTTPS.

Works from any previous version, including 2.6.x, since the bootloader is refreshed along with the app.

Configure the node

Send your settings to the node over the same USB cable, no phone app needed. Nothing leaves the browser until you press Connect and apply, and every field is remembered so you can run the same settings onto node after node.

Works on any node running Meshtastic 2.6 or newer, flashed from this page or not. Chrome or Edge on desktop.

    Buttons after flashing

    Toggle down / upNext / previous screen. Inside a menu: next / previous item.
    Toggle pushOpen the menu for the current screen, or select the highlighted item.
    Side button, short pressOpen the preset message list (broadcast on the primary channel). Press again to close it.
    Side button, hold 0.5 sBack. Closes any menu or list.
    Side button, hold 4 sShutdown.

    Required node config

    Canned messages module enabled, updown1_enabled on, pins A / B / press set to your toggle GPIOs (26 / 19 / 20 on the Muzi H1 remix), and device.button_gpio left at 0.

    Never accept an over-the-air update from the phone app. It reinstalls stock firmware and the toggle stops working again.
